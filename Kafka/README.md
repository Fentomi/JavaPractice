# Практическое задание по Kafka
## Цель:

Разработать автоматизированные тесты для проверки функциональности Kafka-микросервиса обработки заказов. Приложение нужно поднять через Testcontainers (изолированный Kafka в Docker). Основная задача — самостоятельно разработать тест-кейсы и реализовать их на Java с использованием Spring Kafka Test + JUnit 5.

## Описание задания

Вам необходимо протестировать асинхронный пайплайн: Producer → [orders.created] → Consumer (валидация) → [orders.processed]

Функционал для тестирования: 1)Продюсер отправляет событие OrderEvent в тему orders.created. 2)Консьюмер читает событие, валидирует поле amount > 0. 3)Результат (OrderResult со статусом ACCEPTED/REJECTED) отправляется в тему orders.processed.

Вам предстоит: Разработать собственные тест-кейсы на основе сценариев работы с Kafka. Реализовать их в виде автоматизированных интеграционных тестов. Написать не менее 1 позитивного и 1 негативного тест-кейса.

## Требования к выполнению задания:

IDE IntelliJ IDEA / Eclipse Язык Java 17+ Build Tool Maven или Gradle Библиотеки Spring Kafka, Spring Boot Test, Testcontainers (Kafka), JUnit 5, Awaitility, Jackson DTO/POJO Использовать Java-классы для сериализации/десериализации сообщений Data-Driven Подавать тестовые данные из CSV/JSON-файла или через @MethodSource Параллелизм Отчетность Каждый тест должен логировать результат; использовать @ExtendWith(SpringExtension.class) и стандартные ассерты JUnit
